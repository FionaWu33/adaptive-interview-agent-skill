# Adaptive Interview Agent Skill

一个面向具体岗位的 Adaptive Interview Agent Skill：区分面试阶段，根据候选人每轮回答动态调整追问，并通过复盘改善下一场训练。

## 产品定位

它不是固定题库，也不依赖固定模型。宿主 Agent 读取本 Skill 后，根据用户提供的 JD、简历、项目材料和对话记录执行面试方法。

核心能力：

- 区分专业一面、业务负责人 / 二面和 HR 面；
- 根据阶段启用不同考察模块；
- 以澄清、深挖、挑战、切题和结束驱动逐轮追问；
- 支持模拟面试，也支持用户粘贴真实面试记录复盘；
- 将复盘中的下一轮重点带入后续训练。
- 支持标准模式与压力模式；压力模式会更直接地检验个人贡献、证据、指标、取舍、风险与能力边界，但不使用羞辱、抬杠或无关刁难。

它不提供固定题量、评分准确率、雷达图、商业化成果或真实用户量声明。

## 安装与使用

将 `adaptive-interview-agent` 目录安装到宿主 Agent 可发现的 Skill 目录，或在当前仓库中按路径引用。触发示例：

- “这是 JD 和简历，请帮我做一场专业一面。”
- “针对 RAG 项目继续追问我的上一轮回答。”
- “这是我真实面试的逐字稿，请复盘并给下一场训练重点。”
- “请用压力模式帮我做一场业务负责人二面。”

详细执行流程见 [SKILL.md](SKILL.md)。
